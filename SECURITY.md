# Security Policy

Please do not open a public issue for a security problem. Report it privately
through
[GitHub Security Advisories](https://github.com/dannyota/greennode/security/advisories/new).

Reports about credential handling, token storage, requests sent to the wrong
host, and writes that run without the documented confirmation are especially
welcome.

Never include real credentials, tokens, account identifiers, or resource
identifiers in a report.
